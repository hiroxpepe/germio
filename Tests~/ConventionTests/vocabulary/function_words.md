# Function Words

Words a naming check has no need for (a pronoun, an article, a
question word), but real prose cannot do without. Kept apart from
basic_words.md on purpose: adding these there would let a naming
check pass an identifier built from a sentence fragment (`SheIs`).
This file is read only when checking prose text, never when checking
an identifier name.
